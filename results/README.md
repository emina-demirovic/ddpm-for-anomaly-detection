# Results Summary

This folder contains small evaluation artifacts selected for presentation and discussion.

## initial_eval
Initial mini-evaluation results obtained on a small unbalanced subset.
Included:
- metrics summary
- anomaly score table
- anomaly map visualizations

## balanced_eval
Mini-evaluation results obtained on a balanced subset.
Included:
- anomaly score table
- visualization panels

## Note
Model checkpoints and large binary files are intentionally excluded from this repository.
Only lightweight and presentation-relevant result files are included.
